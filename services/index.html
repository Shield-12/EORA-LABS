Limited pilot engagements

Services for small organizations that need clearer systems, safer access, and better documentation.

I accept limited, scoped pilot engagements where I can assess, document, standardize, and improve small-organization IT environments. This is not a 24/7 managed-services storefront. It is a focused services page for practical assessment, identity cleanup, documentation, endpoint standardization, automation, and infrastructure planning.

Start a scoped conversation View technical evidence

Service posture

Assess first. Then improve deliberately.

The goal is to help a small clinic, law office, nonprofit, or small firm understand its current technology condition and define realistic next steps before anyone starts changing production systems.

01

Technology Assessment & Modernization Plan

I review the current environment, identify risks and weak points, document the system inventory, and produce a prioritized improvement plan. This is the safest starting point because it separates observation from implementation.

  • Discovery
  • Risk review
  • Documentation
  • Roadmap

02

Microsoft 365 Identity & Security

I help review user accounts, license usage, MFA posture, mailbox and group structure, stale access, and basic administrative hygiene within a defined scope.

  • M365
  • MFA
  • Groups
  • Access review

03

Documentation & Continuity

I create practical documentation for accounts, devices, vendors, support procedures, recovery notes, and repeatable workflows so knowledge does not live only in one person’s head.

  • Runbooks
  • Inventory
  • Handoff
  • Continuity

04

Administrative Automation

I build small, understandable PowerShell workflows for repeatable administrative tasks such as exports, inventory checks, user data review, or structured reporting.

  • PowerShell
  • Exports
  • Repeatability
  • Reporting

05

Endpoint Deployment Pilot

I help define a small endpoint standardization pilot: naming, setup checklist, baseline apps, account access, update posture, documentation, and handoff expectations.

  • Windows
  • Checklist
  • Standardization
  • Handoff

06

Windows Server & Hybrid Infrastructure Planning

I can help small environments reason through Active Directory, DNS, DHCP, file services, Group Policy, server role separation, backup expectations, and future modernization paths. Implementation work should follow assessment and written scope.

  • AD DS
  • DNS
  • DHCP
  • GPO
  • Planning

Boundaries

What this is not

Clear scope protects both sides. I do not present this page as a full managed-services operation, emergency support desk, or compliance guarantee.

  • No 24/7 managed support commitment.
  • No guaranteed HIPAA, SOX, PCI, or regulatory compliance outcome.
  • No undocumented administrator access.
  • No open-ended production changes without written scope.
  • No emergency break-fix promise without a defined agreement.
