Quick rundown

I help small organizations make their IT environment easier to understand, support, and improve.

Many small teams have technology that works just well enough to keep the day moving, but not well enough to be documented, reviewed, standardized, or handed off confidently. That is where I can help.

  • Who I help: small clinics, law offices, nonprofits, departments, and small businesses using Microsoft 365, Windows endpoints, shared accounts, file access, vendors, or legacy workflows.
  • What I do first: assess the current environment, identify risk, document what exists, and create a realistic improvement plan.
  • What I can improve: Microsoft 365 identity hygiene, MFA posture, documentation, endpoint setup standards, administrative automation, and Windows infrastructure planning.
  • How I work: define the scope, gather evidence, explain the trade-offs, document the result, and avoid unnecessary production changes.

Services

Practical help for environments that need order before scale.

These services are designed to give an organization clarity, safer access practices, better documentation, and a defined path forward before committing to larger changes.

01

Technology Assessment & Modernization Plan

I review the current environment, identify risks and weak points, document the system inventory, and produce a prioritized improvement plan. This is the safest starting point because it separates observation from implementation.

  • Discovery
  • Risk review
  • Documentation
  • Roadmap

02

Microsoft 365 Identity & Security Review

I help review user accounts, license usage, MFA posture, mailbox and group structure, stale access, and basic administrative hygiene within a defined scope.

  • M365
  • MFA
  • Groups
  • Access review

03

Documentation & Continuity Cleanup

I create practical documentation for accounts, devices, vendors, support procedures, recovery notes, and repeatable workflows so knowledge does not live only in one person’s head.

  • Runbooks
  • Inventory
  • Handoff
  • Continuity

04

Administrative Automation

I build small, understandable PowerShell workflows for repeatable administrative tasks such as exports, inventory checks, user data review, or structured reporting.

  • PowerShell
  • Exports
  • Repeatability
  • Reporting

05

Endpoint Setup & Standardization Pilot

I help define a small endpoint standardization pilot: naming, setup checklist, baseline apps, account access, update posture, documentation, and handoff expectations.

  • Windows
  • Checklist
  • Standardization
  • Handoff

06

Windows Server & Hybrid Infrastructure Planning

I can help small environments reason through Active Directory, DNS, DHCP, file services, Group Policy, server role separation, backup expectations, and future modernization paths. Implementation work should follow assessment and written scope.

  • AD DS
  • DNS
  • DHCP
  • GPO
  • Planning
